# Roadmap

1. PDF pages as native Typst text so that text stays selectable; mouse drag selection and
   double-click word selection in the text editor.
2. Python: a `pyproject.toml` so the package installs with pip; running a macro on every slide from the converter CLI.
3. Editor: adding shapes, placeholder styles in the layout editor.
4. PDF export options (one page per build step, notes pages); single-file `.deck` zip.
5. Master text styles, theme colors and tables in the PPTX import; motion paths as steps.
6. Installers published from CI for Linux and Windows.
