# API reference

The rustdoc of the crates is published next to this manual:

- [deck-core](api/deck_core/index.html): the document model, the native format, the SVG
  renderer.
- [deck-convert](api/deck_convert/index.html): PPTX import and export.

Locally:

```bash
cargo doc --no-deps -p deck-core -p deck-convert --open
```
