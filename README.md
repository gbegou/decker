# decker

A free, fast, modern alternative to PowerPoint, written in Rust, for Linux and Windows.
Python macros, a presenter mode, and a converter for PPTX files.

Status: first draft. The document model, the native format, an SVG renderer and the
PPTX converter exist. The editor and the presentation windows (Tauri) come next.

## Layout

| Crate | Content |
| --- | --- |
| `crates/deck-core` | Document model (`Deck` → `Slide` → text, image, shape), native format, SVG renderer |
| `crates/deck-convert` | Command-line converter: PPTX import, PPTX export, SVG render |
| `apps/deck-app` | Tauri application: editor, presentation window, presenter mode, embedded Python macros (planned) |

## Native format

A deck is a folder `<name>.deck/`:

```text
talk.deck/
  deck.json     # the model, with a "version" field for migrations
  assets/       # images, referenced by deck-relative path
```

Coordinates are in points (1/72 inch), origin at the top-left of the slide; a 16:9 slide is
960 x 540 points. A single-file (zipped) variant is planned.

## Converter

```bash
cargo build --release
```

```bash
target/release/deck-convert import talk.pptx          # → talk.deck/
```

```bash
target/release/deck-convert render talk.deck          # → talk.deck/svg/slideN.svg
```

```bash
target/release/deck-convert export talk.deck -o out.pptx
```

```bash
target/release/deck-convert info talk.deck
```

### What the PPTX import handles

- Slide size and order, slide names, solid background colors, speaker notes.
- Text: paragraphs with alignment and bullet level, runs with bold, italic, size, color and font.
- Placeholders without an explicit position inherit it from the slide layout, then the master.
  Body placeholders are bulleted, titles get 44 pt and subtitles 24 pt when the run sets no size
  (the master's text styles are not read yet).
- Pictures (png, jpeg, gif, bmp, svg, webp), copied into `assets/`.
- Shapes: rectangles (and rounded variants), ellipses, lines and connectors, with solid fill,
  outline and text. Other preset geometries are drawn as rectangles.
- Groups, with their child-to-slide transform.

Skipped, with a warning on stderr: tables, charts, SmartArt, embedded objects, gradients,
theme colors, animations and transitions. The old binary `.ppt` format is not read; convert it
with LibreOffice first (`soffice --headless --convert-to pptx`).

### Export

Writes a minimal package (one blank master and layout, a theme, notes) with every element as an
explicit shape. Verified by re-importing with decker and by opening with python-pptx.

## Development

```bash
cargo fmt --all -- --check && cargo clippy --all-targets -- -D warnings && cargo test
```

The fixture `tests/fixtures/fixture.pptx` is generated by python-pptx; the tests import it
and round-trip a deck through export and import.

## Roadmap

1. Tauri editor: slide list, canvas, properties panel.
2. Presentation window on a chosen monitor, presenter mode (notes, next slide, timer).
3. Embedded Python (PyO3) exposing the document model as a macro API.
4. PDF export from the SVG renderer; single-file `.deck` zip.
5. Master text styles, theme colors and tables in the PPTX import.
